# Portfolio Labs

This folder contains my selected TryHackMe lab documentation.

Each lab is organized as a student-level writeup with a clear goal, tools used, key observations, screenshots, mistakes, and a short reflection.

The goal is not only to show completed rooms, but to document what I practiced and how each lab supports my cybersecurity learning path.
