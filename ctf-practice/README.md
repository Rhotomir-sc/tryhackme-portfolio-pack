# CTF Practice

This folder contains beginner-friendly CTF-style practice notes.

The goal of this section is not to present advanced offensive security work.  
It is used to document small problem-solving exercises, basic enumeration practice, and lessons learned from beginner-level challenges.

---

## Purpose

This folder answers one main question:

> What did I practice outside the main portfolio labs?

This section may include:

- Beginner CTF notes
- Basic enumeration practice
- Simple Linux or networking challenges
- Small problem-solving writeups
- Mistakes and lessons learned during practice

---

## Documentation Standard

Each CTF practice note should include:

- Challenge goal
- Tools or commands used
- Short solving process
- What I learned
- Mistakes or confusing parts
- Final reflection
